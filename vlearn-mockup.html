REST API

Introduction to REST API

⏱ 12 phút 📚 5 chunks 🧠 Beginner

📖 Mô tả bài học

Bài học giới thiệu về REST API, một kiến trúc phổ biến trong thiết kế web service. Bạn sẽ học về các HTTP methods, status codes và nguyên tắc stateless.

🎯 Mục tiêu học tập

  • Giải thích được REST API là gì và các đặc điểm chính
  • Phân biệt được Client – Server trong kiến trúc REST
  • Nắm được các HTTP Methods: GET, POST, PUT, DELETE
  • Đọc hiểu HTTP Status Codes phổ biến
  • Hiểu nguyên tắc Stateless trong REST

00:00 — Giới thiệu: REST (Representational State Transfer) là một kiến trúc được Roy Fielding giới thiệu năm 2000...

02:15 — Client – Server: Trong mô hình REST, client và server là hai thực thể tách biệt. Client gửi request, server xử lý và trả response...

05:00 — HTTP Methods: GET dùng để lấy dữ liệu, POST để tạo mới, PUT để cập nhật toàn bộ, PATCH để cập nhật một phần, DELETE để xóa...

08:30 — Status Codes: 2xx là thành công, 3xx là redirect, 4xx là lỗi client, 5xx là lỗi server...

11:00 — Stateless: Mỗi request đều độc lập, server không lưu trạng thái của client giữa các request...
